# Мини-пэйнт
Демо: https://drawing-app-five-beta.vercel.app/  

В данном проекте реализован холст с тремя кнопками:
- кисть для рисования
- ластик
- кнопка для очищения всего холста
### Стек:
- React
- TypeScript
### Инструкция по запуску:
1. Установить зависимости `npm install`
2. Для запуска `npm run dev`
